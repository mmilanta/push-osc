# Idea

The idea of this website, is to create a website where people can drag and drop osc files. Then the ui shows the edits on real osm data, and check that they are compatible. After reviewing the pearson can click upload. Then there is a auth something where the person can login into osm and approve, and finally the changes are applied.

The person needs to also set a commit message ofc.

## Constraints

The website should be hosted on gh pages

Create a gh repo where you push this folder together with the code that deploys at mmilanta.github.io/push-osc
