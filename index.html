OSM OAuth 2 settings

push-osc uses OSM's OAuth 2.0 with PKCE (no client secret needed). Register an application once:

  1. Open openstreetmap.org/oauth2/applications/new
  2. Name: push-osc (anything works)
  3. Redirect URI:
  4. Leave “Confidential application” unchecked
  5. Scopes: tick read_prefs and write_api
  6. Copy the generated Client ID below
